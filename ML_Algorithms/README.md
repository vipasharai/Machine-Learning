#  Machine Learning Algorithms & Implementations

This directory contains hands-on implementations, mathematical concepts, model persistence, and evaluation for foundational and advanced Machine Learning algorithms.

---

## 📌 Contents & Topics Covered

### 📈 Regression Algorithms

* **Simple Linear Regression (SLR):**
  * `Simple linear Regression (SLR) 1.ipynb`: Data preparation, feature fitting, and regression line visualization.
  * `Simple linear Regression (SLR) 2.ipynb`: Model evaluation metrics (MSE, RMSE, $R^2$ Score) and residual checks.

* **Multiple Linear Regression (MLR) & Model Persistence:**
  * `Multi Linear Regression 1,2 , Pickel .ipynb`: Multi-variable feature modeling, handling multiple independent variables, and saving/loading trained models using Python's `pickle` library for deployment readiness.

* **Polynomial Regression:**
  * `Polynomial Regression.ipynb`: Modeling non-linear relationships by transforming features into polynomial degrees to capture complex data trends.
